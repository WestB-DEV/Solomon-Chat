# Solomon Chat 1.2.0 — private RC2

The composer stays in place while sending. Mobile Enter inserts a newline; use the chat Send button to send. Follow-latest scrolling handles concurrent transcript edits without pulling readers out of history. Mobile layout now clears Obsidian's floating navigation bar.

For a picture wallpaper, add the image to your vault, then open the conversation menu → Chat background → Choose picture → Save. The chooser uses Obsidian's native searchable list. Pictures are local to the vault; direct gallery import and remote URLs are not supported.

## Install

Back up your vault and existing plugin folder. Close Obsidian. Extract the ZIP and copy only main.js, manifest.json and styles.css into `.obsidian/plugins/solomon-chat`. Keep data.json, conversation notes and attachments. Reopen Obsidian; version is 1.2.0. Test in a spare vault first.

To roll back, close Obsidian and restore the three backed-up plugin assets. Keep your notes and data.json.

# Solomon Chat 1.2.1 — mobile Send keyboard patch

Addresses the report that Send closes the keyboard on iPhone 13 in 1.2.0. Mobile Send now handles the complete touch gesture and keeps focus in the composer during activation. It does not refocus after the asynchronous save. Swipes, canceled touches and releases outside Send do not submit; normal click/keyboard activation remains supported.

## Update and retest

In Obsidian, open Settings → Community plugins → Check for updates. Confirm Solomon Chat **1.2.1**, then close and reopen Obsidian. Type and send three messages using the on-screen arrow. The keyboard should stay open and the next draft should accept typing without another tap.

The directory may take time to process this release. Manual installation uses main.js, manifest.json and styles.css in `<vault>/.obsidian/plugins/solomon-chat/` with Obsidian closed. Back up the existing assets and retain data.json, notes and attachments. Restore the backed-up assets to roll back.

## Verification limits

45 unit tests, TypeScript/build, and ten light/dark responsive browser cases pass. The new host-dismiss simulation failed against 1.2.0 (one blur, focus lost) and passes with this patch. Android 15 emulator / Obsidian 1.13.6 physical touch input sent exactly one message, recorded zero textarea blur events, kept focus and followed latest within 0.182 CSS px. Independent code review found no blocking defect.

**Physical iPhone 13 resolution is not yet confirmed.** The browser test models an outside-input touch dismiss handler; it is not an iOS keyboard emulator. Please report whether this patch resolves the issue, including iOS and Obsidian versions if it persists.

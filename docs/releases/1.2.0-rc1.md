# Solomon Chat 1.2.0 — private RC1

The draft composer stays in place when sending, preserving typing continuity. First messages and follow-latest scrolling are more reliable, including during slow saves.

Open the conversation menu and choose **Chat background…** to set a color or a vault-local wallpaper. Use the reset icon for the Obsidian theme. Wallpaper paths are relative to the vault root; remote images are not supported. Message surfaces stay theme-backed for readability.

## Install privately

Back up your vault and existing plugin folder. Close Obsidian, then copy main.js, manifest.json and styles.css into the existing `.obsidian/plugins/solomon-chat` folder. Keep data.json and all conversation notes. Reopen Obsidian and confirm version 1.2.0. Use a test vault first.

## Acceptance status

45 unit tests and ten browser layout cases pass. Native Windows and Android emulator send-continuity smoke tests pass. Physical iPhone and the broader native acceptance matrix remain pending; see the bundled closeout report. This is not an approved public release or a store listing.

## Rollback

Close Obsidian and restore the three backed-up plugin assets, keeping notes, attachments and data.json. New background frontmatter is additive. Stop testing and report any lost/duplicated messages, unreadable bubbles or keyboard/focus regressions, including OS, Obsidian version, theme and reproduction steps. Do not include private journal text in reports.

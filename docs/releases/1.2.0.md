# Solomon Chat 1.2.0

## What's new

- Persistent drafting UI: sending keeps the composer mounted and focus-eligible instead of dismissing and reopening it.
- Reliable follow-latest scrolling, including concurrent note edits and layout changes. Reading older messages preserves your position; use Latest to return.
- Mobile Enter inserts a new line; use the chat's Send button to send.
- Picture wallpapers and colors per conversation. Add your photo to the vault, then choose Chat background → Choose picture → Save.
- Better spacing above Obsidian's floating mobile navigation bar.

## Install or update

Open [Solomon Chat in the Obsidian directory](https://community.obsidian.md/plugins/solomon-chat). Existing users can use Settings → Community plugins → Check for updates. Confirm version 1.2.0; the directory may take time to process the release.

For manual installation, close Obsidian, back up the existing plugin folder, and copy main.js, manifest.json and styles.css into `<vault>/.obsidian/plugins/solomon-chat/`. Keep data.json, notes and attachments. Reopen and enable the plugin. The ZIP contains the same three files.

## Verification and feedback

45 unit tests, ten light/dark responsive browser cases, TypeScript and production build passed. Native Windows and Android emulator smoke tests cover composing and sending; the final native vault wallpaper chooser works on both. Physical iPhone testing is not yet verified, and this release welcomes iPhone feedback.

Report problems at [GitHub Issues](https://github.com/WestB-DEV/Solomon-Chat/issues), including device, Obsidian version, theme and reproduction steps. Do not include private journal content.

To roll back, close Obsidian and restore the three backed-up plugin assets, or use the previous 1.1.0 release assets. Preserve notes, attachments and data.json.
